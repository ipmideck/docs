Sobald eine neuere Version veröffentlicht ist, zeigt ipmideck einmalig eine Benachrichtigung an, und neben der Version in der Seitenleiste bleibt eine Update-Schaltfläche sichtbar, bis Sie sie installieren: ein Pfeil nach oben, bei einer Sicherheitsversion ein Schild. Beide öffnen die Versionshinweise der neuen Version und, wenn ipmideck sie selbst installieren kann, die Schaltfläche **Herunterladen und installieren**.

## Was die Schaltfläche tut

Bevor etwas geändert wird, sichert ipmideck die Datenbank, den Verschlüsselungsschlüssel und `config.yaml` nach `backups/` im [Datenverzeichnis](/de/configuration#wo-die-konfiguration-liegt).

| Installiert mit | Ergebnis |
| --- | --- |
| pip in einer virtuellen Umgebung, pipx, uv | Installiert die neue Version und startet ipmideck neu. Die Seite lädt automatisch neu, sobald die neue Version läuft. |
| pip, pipx oder uv unter Windows | ipmideck wird beendet, damit das Update installiert werden kann; danach starten Sie es erneut. Der Fortschritt wird in `update.log` im Datenverzeichnis protokolliert. |
| Docker mit Watchtower | Watchtower lädt das neue Image und ersetzt den Container. Die Seite lädt automatisch neu. |
| Docker ohne Watchtower | Der Dialog zeigt den Befehl, der auf dem Docker-Host auszuführen ist. |
| git-Checkout, System-Python, editierbare Installation | Der Dialog nennt den Grund und zeigt den auszuführenden Befehl; ein vom System verwaltetes Python wird so aktualisiert, wie es installiert wurde. |

## Voraussetzungen

- Die Anmeldung muss aktiviert sein: Die Schaltfläche ersetzt das laufende Programm.
- Im Demo-Modus ist die Schaltfläche nicht verfügbar.
- Für einen automatischen Neustart muss ipmideck mit dem Befehl `ipmideck` gestartet worden sein. Wurde es anders gestartet, installiert es das Update und fordert Sie zum Neustart auf; unter Windows zeigt es stattdessen den Befehl an.

## Docker mit Watchtower

Ein Container kann sein eigenes Image nicht ersetzen, und Zugriff auf den Docker-Socket würde ipmideck die Kontrolle über den Host geben. Ein separater [Watchtower](https://github.com/nicholas-fedor/watchtower)-Container übernimmt den Austausch, wenn ipmideck ihn anfordert.

<Steps>
  <Step title="ipmideck-Container kennzeichnen">
    Starten Sie ipmideck mit dem Label, das Watchtower die Verwaltung erlaubt:

```bash
docker run -d --name ipmideck --network host \
  --label com.centurylinklabs.watchtower.enable=true \
  -v ipmideck-data:/data devluigi06/ipmideck:latest
```
  </Step>
  <Step title="Watchtower starten">
    Starten Sie Watchtower mit aktivierter HTTP-API, nur vom Host aus erreichbar:

```bash
docker run -d --name watchtower \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -p 127.0.0.1:8080:8080 \
  -e WATCHTOWER_HTTP_API_UPDATE=true \
  -e WATCHTOWER_HTTP_API_TOKEN=replace-with-a-long-random-token \
  -e WATCHTOWER_LABEL_ENABLE=true \
  nickfedor/watchtower
```
  </Step>
  <Step title="ipmideck verbinden">
    Ergänzen Sie die Adresse von Watchtower und das Token im bereits vorhandenen Abschnitt `updates:` von `config.yaml` und starten Sie ipmideck neu:

```yaml config.yaml
updates:
  watchtower_url: http://127.0.0.1:8080
  watchtower_token: replace-with-a-long-random-token
```

    Dieselben Einstellungen gibt es als `IPMIDECK_UPDATES_WATCHTOWER_URL` und `IPMIDECK_UPDATES_WATCHTOWER_TOKEN`. Mit Docker Compose, wo beide Container ein Netzwerk teilen, verwenden Sie `http://watchtower:8080` als Adresse.
  </Step>
</Steps>

<Warning>
  Watchtower steuert Docker über dessen Socket. Verwenden Sie ein langes, zufälliges Token und binden Sie den Port wie gezeigt an `127.0.0.1`.
</Warning>

<Note>
  Watchtower lädt das Tag, das der Container bereits verwendet. Mit `latest` wechselt es zur neuesten Version; ein auf ein Versions-Tag festgelegter Container (zum Beispiel `2.0.0`) bleibt auf dieser Version.
</Note>

## Wenn die Installation fehlschlägt

Der Dialog zeigt den Grund und die Ausgabe des Installers sowie den Befehl für eine manuelle Installation. Es wird nichts entfernt: Die vor der Installation erstellte Sicherung liegt in `backups/`, und [Sicherung & Wiederherstellung](/de/backup-restore) erklärt, wie Sie sie wiederherstellen.
