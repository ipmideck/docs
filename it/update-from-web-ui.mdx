title: "Aggiornamento dall'interfaccia web"

---

Quando viene pubblicata una versione più recente, ipmideck mostra una notifica una sola volta e, finché non la installi, accanto alla versione nella barra laterale resta un pulsante di aggiornamento: una freccia verso l'alto, oppure uno scudo per una release di sicurezza. Entrambi aprono le note di rilascio della nuova versione e, quando ipmideck può installarla autonomamente, il pulsante **Scarica e installa**.

## Cosa fa il pulsante

Prima di qualsiasi modifica, ipmideck esegue un backup del database, della chiave di cifratura e di `config.yaml` in `backups/` nella [directory dati](/it/configuration#dove-vive-la-configurazione).

| Metodo di installazione | Risultato |
| --- | --- |
| pip in un ambiente virtuale, pipx, uv | Installa la nuova versione e riavvia ipmideck. La pagina si ricarica automaticamente quando la nuova versione è in esecuzione. |
| pip, pipx o uv su Windows | ipmideck si arresta per consentire l'installazione; al termine va avviato di nuovo. L'avanzamento è registrato in `update.log` nella directory dati. |
| Docker con Watchtower | Watchtower scarica la nuova immagine e sostituisce il container. La pagina si ricarica automaticamente. |
| Docker senza Watchtower | La finestra mostra il comando da eseguire sull'host Docker. |
| Checkout git, Python di sistema, installazione modificabile | La finestra spiega il motivo e mostra il comando da eseguire; un Python gestito dal sistema si aggiorna con lo stesso metodo usato per installarlo. |

## Requisiti

- Il login deve essere attivo: il pulsante sostituisce il programma in esecuzione.
- Il pulsante non è disponibile in modalità demo.
- Per riavviarsi automaticamente, ipmideck deve essere stato avviato con il comando `ipmideck`. Se è stato avviato in altro modo, installa l'aggiornamento e chiede di riavviarlo; su Windows mostra invece il comando.

## Docker con Watchtower

Un container non può sostituire la propria immagine, e concedere a ipmideck l'accesso al socket Docker gli darebbe il controllo dell'host. Un container [Watchtower](https://github.com/nicholas-fedor/watchtower) separato esegue la sostituzione quando ipmideck lo richiede.

<Steps>
  <Step title="Etichetta il container di ipmideck">
    Avvia ipmideck con l'etichetta che consente a Watchtower di gestirlo:

```bash
docker run -d --name ipmideck --network host \
  --label com.centurylinklabs.watchtower.enable=true \
  -v ipmideck-data:/data devluigi06/ipmideck:latest
```
  </Step>
  <Step title="Avvia Watchtower">
    Avvia Watchtower con l'API HTTP attiva, raggiungibile solo dall'host:

```bash
docker run -d --name watchtower \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -p 127.0.0.1:8080:8080 \
  -e WATCHTOWER_HTTP_API_UPDATE=true \
  -e WATCHTOWER_HTTP_API_TOKEN=replace-with-a-long-random-token \
  -e WATCHTOWER_LABEL_ENABLE=true \
  nickfedor/watchtower
```
  </Step>
  <Step title="Collega ipmideck">
    Aggiungi l'indirizzo di Watchtower e il token nella sezione `updates:` già presente in `config.yaml`, poi riavvia ipmideck:

```yaml config.yaml
updates:
  watchtower_url: http://127.0.0.1:8080
  watchtower_token: replace-with-a-long-random-token
```

    Le stesse impostazioni sono disponibili come `IPMIDECK_UPDATES_WATCHTOWER_URL` e `IPMIDECK_UPDATES_WATCHTOWER_TOKEN`. Con Docker Compose, dove i due container condividono una rete, usa `http://watchtower:8080` come indirizzo.
  </Step>
</Steps>

<Warning>
  Watchtower controlla Docker attraverso il suo socket. Usa un token lungo e casuale e mantieni la porta associata a `127.0.0.1` come nell'esempio.
</Warning>

<Note>
  Watchtower scarica il tag già usato dal container. Con `latest` passa alla release più recente; un container fissato a un tag di versione (per esempio `2.0.0`) resta su quella versione.
</Note>

## Se l'installazione non riesce

La finestra mostra il motivo e l'output del programma di installazione, insieme al comando per installare l'aggiornamento manualmente. Non viene rimosso nulla: il backup eseguito prima dell'installazione si trova in `backups/` e [Backup e ripristino](/it/backup-restore) spiega come ripristinarlo.
